A. Application Ownership and Contact

Info Asal Mula is a personal, single-user application built and operated solely by its owner, Zul Anggara, for the purpose of uploading, managing, and publishing video content to the owner's own YouTube channel and Instagram account, associated with the social media handle @infoasalmula.

B. Data Access and Permissions

Info Asal Mula only accesses the YouTube and Instagram accounts belonging to its owner, Zul Anggara. The application does not request or obtain access to any account belonging to another person. The following permissions (OAuth scopes) are used, along with the reason each one is required.

Google / YouTube OAuth Scopes:

  • youtube.upload — Upload videos to the owner's YouTube channel.
  • youtube.readonly — Read information about the owner's YouTube account and channel.
  • youtube.force-ssl — Access and manage YouTube account resources through authorized API requests.
  • yt-analytics.readonly — Read analytics and performance data for the owner's YouTube channel.

Meta / Instagram Permissions:

  • instagram_basic — Access basic information about the owner's Instagram account.
  • instagram_content_publish — Publish videos and other supported content to the owner's Instagram account.
  • instagram_manage_comments — Read and manage comments on the owner's Instagram content.
  • instagram_manage_insights — Access insights and performance metrics for the owner's Instagram content.
  • pages_show_list — Retrieve the list of Facebook Pages managed by the owner.
  • pages_read_engagement — Read engagement-related information associated with the owner's Facebook Pages.

C. Data Collection and Sharing

  • The application does not collect personal data from viewers, followers, or commenters.
  • The only exception is the content of a comment, which is processed solely when the owner uses the application to reply to that specific comment.
  • Data is never sold, rented, or shared with any third party.
  • Data is used exclusively to support the application's personal, internal functions.

D. Data Storage and Security

  • OAuth access tokens, refresh tokens, and related credentials are stored only on the owner's own private server.
  • Credentials are never published or displayed publicly.
  • Access to data is restricted to what is operationally necessary for the application to function.
  • Data is protected using reasonable security measures appropriate for a personal, single-user application.

E. User Rights and Data Deletion

As this application is operated by a single owner for their own accounts, access can be revoked directly by the owner at any time through the relevant platform settings:

  • Google: revoke access at https://myaccount.google.com/permissions .
  • Meta / Facebook / Instagram: go to the Business Integrations settings of the connected Facebook or Instagram account to remove the application's access.

Any request regarding data deletion may be submitted to zul.anggara8@gmail.com.
